# AGENTS.md

All guidance for coding agents in this repository lives in
[CLAUDE.md](CLAUDE.md). Read it before you touch anything, and follow it,
regardless of which agent or tool you are.

It covers the repository layout, the test commands, the protocol invariants of
`plugins/buzz-comms/scripts/project-buzz`, the Windows pitfalls, and the writing
conventions (English commit messages, real German umlauts, no en or em dashes,
never amend an existing commit).

`CLAUDE.md` is the single source of truth. If anything here or anywhere else
contradicts it, `CLAUDE.md` wins. Do not duplicate its rules into this file;
extend `CLAUDE.md` instead.
